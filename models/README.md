# 白模工程文件（models）

科目二自动评判器小组项目的白模建模文件。单位均为米（m），1:1 建模。

## 文件说明

| 文件 | 内容 | 物体数 |
|---|---|---|
| `最简桑塔纳白模.obj` | 参考车（新桑塔纳）白模：车身盒 + 座舱盒 + 4 个独立车轮 | 6 |
| `场地白模.obj` | 倒车入库 + 侧方停车场地：地面 + 白线（无材质、无灯光） | 15 |

两个文件均为 Wavefront OBJ，可在 Blender（文件 → 导入 → Wavefront .obj）中按默认轴设置
（向前轴 −Z、向上轴 Y）直接导入；导入后 **+X 为车头方向、Z=0 为地面**。

## 车辆尺寸（以图纸数据为准）

| 参数 | 值 |
|---|---|
| 车长 | 4.473 |
| 车宽 | 1.706 |
| 车高 | 1.469 |
| 轴距 | 2.603 |
| 前悬 | 0.870 |
| 后悬 | 1.000 |
| 轮距 | 1.420 |
| 轮胎半径 / 宽 | 0.300 / 0.195 |

车轮为独立物体（Wheel_FL / FR / RL / RR），轴心在轮心上，可各自绕轮轴旋转，
供后续阿克曼转向回放使用（转向由父级空物体绕 Z 轴、滚动由轮子绕 Y 轴）。

## 场地尺寸

| 区域 | 参数 | 值 |
|---|---|---|
| 倒车入库 | 库宽 × 库深 | 2.31 × 5.17 |
