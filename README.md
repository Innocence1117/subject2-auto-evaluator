# 科目二自动评判器 · subject2-auto-evaluator

> ## ⚠️ 本仓库是 **Public（公开）** 仓库
>
> 写任何文件之前先问一句：**这句话能不能给评委、老师、陌生人看？**
>
> **不要放**：还没定的事（"待核""待定""周五前定"）、内部吐槽或对队友的评价、个人信息（手机号 / 微信 / QQ / 学号）、账号密码、未公开的考场平面图。
>
> 放错一次就会**永久留在 git 历史里**——删掉文件也没用，别人仍然能翻到那次提交。

---

## 这个项目是什么

在浏览器里复现一个科目二考场：学员练完，得到一份"第几秒、哪个车轮、越过哪条线、差多少厘米"的可回放报告。

重点不是画面好看，是**判得对、且能自证**——每一条扣分都能追到规则条文、追到判定时刻、追到具体车轮。

## 目录

| 路径 | 放什么 |
|---|---|
| `docs/` | 给人读的文档（坐标系、用例编号、判罚口径） |
| `tracks/` | 场地数据，每个项目一份 `track.json`，单位米 |
| `src/` | 前端与判定代码 |
| `cli/` | 无 DOM 环境跑判定的入口 |
| `cases/` | 30 条判定用例的轨迹与标注 |
| `models/` | 三维白模（OBJ） |
| `refs/` | 参考资料（标准正文、考场图） |
| `assets.manifest.json` | 资产坐标契约：模型自己的坐标系登记在这里 |

## 快速开始

```bash
pnpm i
pnpm dev     # 本地预览
pnpm test    # 跑测试（含资产坐标契约校验）
```

> 判罚规则表目前只在团队内部维护，未入库。

## 两条硬纪律

1. **判定只读 `track.json`，不读模型。** 模型里的标线只是白模（3cm 宽），规范要求 15cm；拿模型的线去判，画面和判定会差 12cm。
2. **资产可以有私有坐标系，但必须登记。** 改模型不改登记表，`pnpm test` 会红——那是提醒，不是故障。

## 对外产出前的检查清单

要发 PDF、PPT、答辩材料、给评委的文档之前，过一遍：

- [ ] 没有"待核""待定""还没做""下周定"这类内部状态
- [ ] 没有个人信息与内部联系方式
- [ ] 数字与 `docs/coords.md` 一致（车长 4.473、轴距 2.603、容差 2cm）
- [ ] 判罚口径有依据（GA 1026—2022 条款号），人工判断有署名与日期
- [ ] 不宣称"全国通用考场"——只说"一个可配置的考场"
